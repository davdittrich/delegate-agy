## Alternatives Considered

Mechanism choice: how a documented message is held to the documentation that quotes it, for the messages this phase adds or touches (03-CONTEXT.md D-11 leaves the exact shape to discretion, bounded to "matching the existing `RB03` pattern").

- **Static source-and-README `grep -cF`/`grep -qF` pinning** — `tests/run-tests.sh:2383-2440` (`RB03`, 2026), whose own comment at `:2385-2391` states the discipline. Fewest lines and no wall-clock cost. Its ceiling: it proves what the *source text* contains, not what the program *prints*. A format string can be restructured — a field reordered, a separator moved, a `%s` turned into a concatenation — while the pinned literal survives untouched inside it, and the check stays green over drifted output.
- **Runtime provocation with byte-exact comparison** — the suite's own `_run` harness at `tests/run-tests.sh:105-113` and case `R8` at `:497-505` (2026). Costs one process spawn per scenario and, for the timeout codes, roughly the bound in wall-clock. It observes the actual bytes an operator would see, which is the property criterion 4 is written about.
- **Golden-file snapshot fixtures under `tests/fixtures/`** — the mechanism established for captured real-`agy` output in `.planning/phases/01.5-contract-check-against-a-real-agy/01.5-CONTEXT.md` §D-14/D-14a (2026). Rejected on two counts: it adds new files and a diff harness to pin eight short strings, and D-14a deliberately reserves that directory for *captured* real-agy output, so putting synthetic expectations there erodes the captured-versus-synthetic separation that phase established.

**Decided by: maintenance.** The three are close enough on performance and ecosystem that neither decides it, and the static form wins on raw LOC. Maintenance decides against it: a static-only pin goes stale the moment a format string is restructured without the literal changing, and re-detecting that requires a manual re-audit — which is precisely how `delegate-agy-6q1` reached a shipped release. This phase therefore uses the static pin for provenance (plans `03-02` `EC05`, `03-03` `EC06`) and runtime provocation for output shape (`EC01`-`EC04` and this plan's `EC07`/`EC08`), paying the wall-clock only where a static check is structurally blind.
