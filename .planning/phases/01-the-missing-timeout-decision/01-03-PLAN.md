Give the bridge the same treatment the shim got, and delete the fatal that made the two diverge in the first place.

Purpose: `delegate-agy-cy5` was filed because the bridge treats a missing `timeout` binary as fatal while the shim degrades to an unbounded call. After this plan the two entry points do the same thing for the same reason, which is what criterion 1 asks to be recorded and criterion 3 asks to be readable.

Output: `run_bounded` duplicated byte-for-byte into `scripts/agy_bridge.sh`, the startup `exit 2` on a missing bounding binary removed and replaced by one warning, and all three bridge call sites bounded.
</objective>

<assumption_delta_decision>
**Signal:** pluralization of "fallback".

**Noun now primary:** the *bounded invocation* (`run_bounded`), not the `timeout` binary. The bridge is the sharper case: it never had a fallback branch at all, because it refused to start without the binary. After this plan it has no branch and no refusal — it has a helper.

**Decision: `promote`.** `run_bounded` is the primary; coreutils `timeout -k` is one of its two internal mechanisms (D-04, D-05). Not `add-alongside` — the bridge gains no mechanism-aware conditional at any site, and loses the startup fatal that stood in for one.

**Test encoding the generalized intent:** the D-12/D-13 static scan (plan 01-05, case RB01) goes red the instant a future site reintroduces the singular assumption by invoking agy directly.
</assumption_delta_decision>

## Alternatives Considered

- **Keep the bridge's startup fatal and document the divergence** (`.planning/ROADMAP.md` § Phase 1 criterion 1, candidate design (a), 2026; `.planning/PROJECT.md` § Key Decisions, "Shim degrades silently, bridge fails loud", 2026): the roadmap's own first candidate, and the cheapest change — write down why the two differ and stop. Rejected because the fatal's entire justification was that an unbounded call is worse than a refusal, and with a native watchdog there is no unbounded call to be worse. Documenting a divergence that no longer needs to exist preserves a defect as a feature. Decided by: simplicity.
- **Refuse only the delegation call, degrade for everything else** (`.planning/ROADMAP.md` § Phase 1 criterion 1, candidate design (c), 2026): would keep the strongest guarantee where the longest bound lives. Rejected because it leaves the model fetch and the stdin read unbounded, so `agy-bridge --types` on a coreutils-less host can still hang indefinitely, and it makes the bridge's behaviour depend on which subcommand you ran — a second divergence in place of the one being removed. Decided by: simplicity.
- **Extract `run_bounded` into a sourced library instead of duplicating it** (https://www.gnu.org/software/bash/manual/bash.html#Bourne-Shell-Builtins, bash 5.3.15 verified on this host 2026-08-19): the obvious answer to two copies of the same code. Rejected because the shim must work as a lone drop-in at `~/.local/bin/gemini` and nothing in either script is sourced today; a shared file would cost the shim its standalone property and add a runtime path that can go missing on exactly the hosts this phase exists for. The in-repo precedent for this tradeoff is already written down at `scripts/gemini_shim.sh:58-61` for the model-name mapping. Decided by: maintenance.
- **Enforce non-divergence with a shared file plus a symlink** (https://man7.org/linux/man-pages/man1/ln.1.html, man-pages 6.x, 2024): would make drift structurally impossible. Rejected for the same standalone-drop-in reason, and because a symlink does not survive the installer's copy-to-`~/.local/bin` step. A byte-identity test costs one case and no runtime risk. Decided by: maintenance.
