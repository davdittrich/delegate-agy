| plugin registry → generated wrapper | The wrapper reads `installed_plugins.json` for comparison; a matched entry influences what the wrapper prints, though never what it execs |
| working tree → release artifact | An install from the working tree would ship uncommitted state; the clone boundary is what prevents it |
