<objective>
Two behavioral defects in the two shipped scripts, each a one-branch fix with a new behavioral test:

- **D-04 / `delegate-agy-ltf`** — `gemini_shim.sh`'s unknown-long-flag catch-all consumes the token after the flag whenever that token does not itself start with `-`. A user's prompt is exactly such a token, so `gemini --froboz "write me a haiku"` silently loses the prompt. Fix: shift once, never twice.
- **D-07 / `delegate-agy-b7g`** — a successful `agy models` that returns zero bytes, with no cache on disk, matches neither arm of the bridge's fetch `if/elif` and falls through to a generic "failed to retrieve model list" bail, discarding the diagnostic that would tell the user agy is unauthenticated. Fix: set a flag in a new `else` arm and branch on it at the bail that already exists.

Purpose: both are user-facing data-loss or diagnostic-loss defects on the paths users actually hit — a swallowed prompt and a misdiagnosed auth failure.
Output: two single-branch source changes, two new harness cases (`SH16`, `R9f`), and one new fake-agy mode to drive the zero-byte reply.

Both fixes are proven test-first. This plan uses task-level TDD (`tdd="true"` with an explicit RED gate in each task) rather than one dedicated TDD plan per feature: every case in this phase lands in the single file `tests/run-tests.sh`, so splitting one feature per plan would buy three extra serialization waves and no additional verification. The RED→GREEN discipline is preserved in full — each task's `<done>` requires the case observed failing before the fix exists.
</objective>
