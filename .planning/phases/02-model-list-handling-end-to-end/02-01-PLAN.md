## Alternatives Considered

**A. How the degraded-list test is expressed at the write site.**

- **Normalize into a variable first, then a two-element `printf | grep -q` pipeline (chosen)**: mirrors `scripts/agy_bridge.sh:510` and `:515` exactly, so the write-time gate and the use-time check are one rule rather than two that can drift. It also keeps the pipeline two elements long under `set -o pipefail`, where a `grep -q` that closes the pipe on its first match can leave a middle `cut` dead of SIGPIPE and hand the whole pipeline status 141 — which the enclosing `if` would read as "degraded" for a perfectly good list. Citation: `scripts/agy_bridge.sh:8`, `:510`, `:515`, read on `fix/agy-bridge-resilience` (2026); GNU Bash Reference Manual §3.2.4 "Pipelines" on `pipefail` returning the rightmost non-zero status, bash 5.2 (2022) — <https://www.gnu.org/software/bash/manual/html_node/Pipelines.html>.
  Decided by: performance — the alternative's failure mode is a false degraded verdict on a good list, which is a worse outage than the bug being fixed.
- **One three-element pipeline, no temp variable**: a line shorter. Rejected for the `pipefail`/SIGPIPE hazard above. It is safe today only because a 14-row model list fits inside the 64 KiB default pipe buffer, so `cut` finishes writing before `grep -q` can close the read end — a correctness argument that depends on the size of agy's reply, which is exactly the thing S1 says this project does not control. Citation: `pipe(7)` on the 65536-byte default pipe capacity, Linux man-pages 6.9.1 (2024) — <https://man7.org/linux/man-pages/man7/pipe.7.html>; `tests/fixtures/agy-models.tsv`, 14 rows captured 2026-08-20.
  Decided by: performance — a latent, size-dependent false negative is not a saving.
- **Grepping the raw reply for `^gemini-` without normalizing**: shortest of all, and equivalent for every reply shape observed so far, since `^` anchors at line start and the id is column 1. Rejected because it states the degraded-list rule a second time in a second form: `:510` normalizes before `:515` greps, and two forms of one rule is precisely the drift S1 exists to prevent — the 1.6.1 incident was a matcher and an input format disagreeing. Citation: `.planning/REQUIREMENTS.md` §S1 origin (2026); `02-CONTEXT.md` §D-03, "reusing it, not inventing a second check" (2026).
  Decided by: maintenance — one rule that cannot drift beats one line saved.
