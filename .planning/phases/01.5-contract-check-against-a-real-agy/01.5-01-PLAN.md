Citation: `01.5-RESEARCH.md` §"`run_bounded`'s complete external contract" and §Pattern 1 (2026); `01-CONTEXT.md` §D-08, the duplication-plus-identity-test rule this extends (2026). **Decided by: simplicity** — the check gets a bound whose behavior is already mutation-tested in fourteen cases, and the only new artifact is a `sed`-extractable copy plus one more equality leg in RB02.
- **Extract the helper into a sourced `tests/lib/run_bounded.sh`**: one copy instead of three. Rejected because sourcing costs `scripts/gemini_shim.sh` its standalone property, which is the entire reason D-08 chose duplication in the first place; a shim that cannot be dropped onto a box as one file stops being a drop-in `gemini` replacement. Citation: GNU Bash Reference Manual §4.1 `source` / `.` semantics, bash 5.3 (2025) — <https://www.gnu.org/software/bash/manual/bash.html>. **Decided by: simplicity** — a shared file trades three sed-comparable copies for a load-path dependency in two shipped standalone binaries.
- **Hard-require coreutils `timeout -k` and drop the watchdog arm**: smallest possible implementation, no copied block at all. Rejected because it makes the check unrunnable on exactly the hosts Phase 1 existed to serve (stock macOS with no `gtimeout`), and it would leave the bash-watchdog arm with no live exercise anywhere in the repo. Citation: GNU Coreutils Manual §`timeout` invocation, coreutils 9.7 (2025) — <https://www.gnu.org/software/coreutils/manual/html_node/timeout-invocation.html>. **Decided by: ecosystem** — the dependency is documented as recommended-not-required at `README.md:44`, and a maintainer tool that silently raises the floor contradicts the shipped promise.

**Ledger output shape.** No analog exists in this repo (`01.5-PATTERNS.md` §"No Analog Found" states this plainly, 2026); D-04 explicitly rejects reusing `run-tests.sh`'s `ok`/`bad`/`PASS=n FAIL=n` bookkeeping so nobody wires a verdict into a gate by muscle memory. The alternatives weighed were plain-text rows (chosen — greppable by `grep -qE '^agy-version-shape +verified'`, no parser dependency) versus a JSON envelope emitted through `python3 -c` the way `scripts/gemini_shim.sh:432-463` already does.
