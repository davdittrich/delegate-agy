## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] CC01's outer `timeout` wrapper unresolvable under its own fully-replaced PATH**
- **Found during:** Task 3, first CC01 run
- **Issue:** `_PUREBIN_TOOLS` (the existing whitelist `_purebin()` uses) does not include `timeout`, because every existing caller of that whitelist keeps the harness's original PATH available for its own outer safety net. CC01 is the first case to replace PATH wholesale for the outer bound as well as the bounded child, so a bare `timeout 30 ...` invocation failed outright (`rc=127`, "timeout: command not found") instead of ever reaching `contract-check.sh`.
- **Fix:** CC01's scratch PATH directory is built from `_PUREBIN_TOOLS` plus an explicit `timeout` entry (resolved from the harness's own PATH before the sanitized directory is built, same resolution pattern `_purebin()` already uses for every other tool).
- **Files modified:** `tests/run-tests.sh`
- **Verification:** CC01 passes; full suite `PASS=127 FAIL=0`; mutation-proved separately (see Task Commits).
- **Committed in:** `66085e2` (Task 3 commit)
