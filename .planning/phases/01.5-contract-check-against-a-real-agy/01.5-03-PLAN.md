## Alternatives Considered

**Extracting the id column from `id<TAB>display name`.**

- **`cut -f1` (chosen)**: the identical normalization the shipped bridge already performs at `scripts/agy_bridge.sh:463-532` before its anchored matchers run. Citation: `01.5-RESEARCH.md` §"Model resolution — what the check must re-derive, not assert" (2026); POSIX `cut` specification, IEEE Std 1003.1-2024 (2024) — <https://pubs.opengroup.org/onlinepubs/9799919799/utilities/cut.html>.
  Decided by: maintenance — the check re-derives with byte-identical logic, so a divergence between what the check reports and what the bridge would actually select is structurally impossible; any other extraction creates a second definition of "the id column" that can drift.
- **`awk -F'\t' '{print $1}'`**: equally correct on well-formed input and marginally more flexible on ragged rows. Rejected because flexibility is the wrong property here: the probe exists to *detect* ragged rows, and an extractor that quietly tolerates them would hide the drift shape S1 exists to catch. Citation: GNU Awk User's Guide §4.5 field splitting, gawk 5.3 (2024) — <https://www.gnu.org/software/gawk/manual/gawk.html>.
  Decided by: maintenance.
- **Bash parameter expansion `${line%%$'\t'*}`**: no subprocess at all, the fastest of the three. Rejected because it diverges from the shipped normalization and buys nothing measurable on a 14-line list. Citation: GNU Bash Reference Manual §3.5.3 shell parameter expansion, bash 5.3 (2025) — <https://www.gnu.org/software/bash/manual/bash.html>.
  Decided by: maintenance — same reason; performance is not the binding constraint on a 14-row input.

**Gating billed probes behind a preflight.**

- **Unconditional cheap preflight, no flag (chosen)**: bounded `agy --version` and `agy models` run first; a failure of either routes every delegation-dependent assumption to `unverified` with zero spend. LOCKED by D-13. Citation: `01.5-CONTEXT.md` §D-13 (2026); Antigravity CLI headless docs describing the `--print` non-interactive path and its default `--print-timeout` (2026) — <https://antigravity.google/docs/cli/headless>.
  Decided by: performance — the two cheapest calls in the set decide whether any expensive call happens, so the worst case for an unreachable or unauthenticated agy is two bounded failures rather than three billed timeouts.
- **A tiered `--full` flag**: default run stays free, billed probes opt-in. Rejected in D-13: the default run would then be unable to satisfy criteria 1 and 3, making the useful mode the non-default one. Citation: `01.5-CONTEXT.md` §D-13 (2026).
  Decided by: simplicity — one mode, no flag surface, no way to run the check and get a ledger that silently omits three of seven rows.
- **An interactive confirmation prompt before spending**: safest for quota. Rejected in D-13: it makes the check non-scriptable without also adding a `--yes` surface, which is two new behaviours to document instead of zero. Citation: `01.5-CONTEXT.md` §D-13 (2026).
  Decided by: simplicity.
