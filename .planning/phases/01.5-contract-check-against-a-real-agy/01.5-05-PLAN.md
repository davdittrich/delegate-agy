## Alternatives Considered

**How the SIGTERM assumption is observed.**

- **A genuinely slow real delegation against a strict short bound, signalled at the bound, discriminating 124 from 137 (chosen)**: LOCKED by D-12, with D-12a requiring the payload shape and the exact bound to be stated. Citation: `01.5-CONTEXT.md` §D-12, §D-12a (2026); GNU Coreutils Manual §`timeout` invocation on `-k` and the exit status it reports, coreutils 9.7 (2025) — <https://www.gnu.org/software/coreutils/manual/html_node/timeout-invocation.html>.
  Decided by: simplicity — of the options that can actually answer the question, this needs one bounded call and one exit-code read.
- **Signalling the `models` subcommand instead**: far cheaper, non-generating, no quota at all. Rejected in D-12 on a correctness ground: `models` may not share the delegation path's process tree, so a clean death there would not license R11's `-k` on delegations. A cheaper probe that cannot answer the question is not a viable rung. Citation: `01.5-CONTEXT.md` §D-12 (2026).
  Decided by: simplicity — among *viable* options only.
- **Attaching a tracer (`strace` / `dtruss`) to observe signal disposition directly**: the only option that would answer definitively rather than behaviourally. Rejected because it adds a platform-specific privileged dependency to a maintainer tool that must run on stock macOS as well as Linux, and it observes the wrong layer anyway: what R11's `-k` depends on is whether the process *dies*, not whether it installs a handler. Citation: `strace` man page, strace 6.9 (2024) — <https://man7.org/linux/man-pages/man1/strace.1.html>; `01.5-RESEARCH.md` §Pitfall 6 recording that no authoritative source for agy's signal handling exists anywhere (2026).
  Decided by: ecosystem — a privileged, Linux-only tool cannot be a dependency of a check whose whole point is running where dependencies are thin.

**How the `GEMINI.md`-binding assumption is probed.**

- **Through the real bridge, with a shipped policy that forbids a tool, asserting the tool is actually refused (chosen)**: LOCKED by D-10. Citation: `01.5-CONTEXT.md` §D-10 (2026); `01.5-RESEARCH.md` §"GEMINI.md policy-file construction" quoting `scripts/agy_bridge.sh:549-561,611-617` (2026).
  Decided by: simplicity — the bridge already assembles the policy, sets the flags and orders `--add-dir` correctly; reproducing that by hand would be a second implementation of the thing under test.
- **The bare-CWD probe**: run agy from a throwaway directory and ask what `GEMINI.md` files it can see. Rejected in D-10: it reproduces an observation already recorded on `delegate-agy-xfa` and leaves the ticket's actual question — whether the `--sandbox` and `--add-dir WORK_DIR` the bridge additionally passes constrain discovery — unanswered. Citation: `01.5-CONTEXT.md` §D-10 (2026); Antigravity CLI permissions docs on Deny > Ask > Allow precedence (2026) — <https://antigravity.google/docs/cli/permissions>.
  Decided by: simplicity — the cheaper probe answers a question already answered.
- **A bespoke one-off policy file written for the probe**: maximum control over what is forbidden. Rejected by CONTEXT.md's discretion constraint: the policy must be shaped like the existing `config/policies/*.md` files, because the probe's value is that it measures the shipped configuration. All seven policy files already forbid the same tool, so no new file is needed. Citation: `01.5-CONTEXT.md` §"Claude's Discretion" (2026).
  Decided by: LOC — zero new files versus one, for identical coverage.
